Tentang Saya

Saya Arraffi AMF, dikenal online sebagai Konaima, seorang junior backend engineer dari Jawa Tengah, Indonesia. Saya membuat API, layanan backend, dan deployment Linux dengan Node.js dan Python.

Sebagian besar waktu saya habiskan buat menelusuri request yang lambat, memperbaiki deploy yang gagal, dan menjaga database serta layanan VPS tetap bisa dipakai. Saya lebih suka pekerjaan yang praktis: cari masalahnya, pahami penyebabnya, lalu buat sistemnya lebih mudah dijalankan.
