Tentang Saya

Halo! Saya Arraffi, seorang pengembang backend yang berdomisili di Jawa Tengah, Indonesia. Saya mengkhususkan diri dalam membangun aplikasi sisi server yang kuat dan mengelola infrastruktur cloud. Perjalanan saya di dunia teknologi dimulai dari rasa ingin tahu tentang bagaimana suatu sistem bekerja di balik layar, yang membawa saya untuk mempelajari Node.js, Python, dan sistem Linux lebih dalam.


Saat saya tidak sedang menulis kode atau mengonfigurasi server, saya senang mengeksplorasi teknologi baru dan membuat alat yang memecahkan masalah dunia nyata. Saya percaya pada pentingnya menulis kode yang bersih, mudah dipelihara, dan membangun sistem yang dapat diskalakan dengan mudah.
